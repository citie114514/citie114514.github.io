## 前言

很多手机玩家想在Android设备上体验Java版Minecraft，但不知道怎么操作。本教程结合两期视频，分别介绍**PojavLauncher**和**HMCL-PE**两个启动器的使用方法，让你在手机上流畅运行Java版MC。

---

## 一、PojavLauncher 启动器

PojavLauncher 是一个开源的 Android 端 Java 版 Minecraft 启动器，支持多种版本和模组加载。

### 1. 下载与安装

首先需要下载以下资源：

| 资源 | 下载地址 |
|------|---------|
| PojavLauncher | [GitHub Releases](https://github.com/PojavLauncherTeam/PojavLauncher/releases) |
| Forge | [files.minecraftforge.net](https://files.minecraftforge.net/) |
| Fabric | [fabricmc.net](https://fabricmc.net/use/) |
| Optifine | [optifine.net](https://www.optifine.net/home) |
| Open4es 光影 | [GitHub](https://github.com/Open4Es/Open4Es-Shader) |

![下载页面](/assets/img/mc-launcher/pojav-download.jpg)

下载完成后安装 APK 文件。

### 2. 登录账号

打开 PojavLauncher，支持以下登录方式：
- **微软账号登录**：推荐，支持正版验证
- **离线模式**：输入用户名即可（仅限单人游戏）
- **选择账号**：管理已登录的账号

![登录界面](/assets/img/mc-launcher/pojav-login.jpg)

### 3. 基本设置

在设置页面可以调整以下参数：

- **Java 运行时环境**：如需重新安装可点击"卸载 Java 运行时环境"
- **长按触发时长**：修改长按的触发时长（默认 500ms）
- **分辨率缩放倍率**：在开销和画面之间取得平衡

选择版本后点击**启动游戏**即可。

![设置界面](/assets/img/mc-launcher/pojav-settings.jpg)

### 4. 进入游戏

启动后进入 Minecraft Java 版主界面，可以看到经典的 Singleplayer、Multiplayer、Minecraft Realms 选项。

![游戏主菜单](/assets/img/mc-launcher/pojav-mc-menu.jpg)

### 5. 操控方式

PojavLauncher 提供虚拟按键操控：
- 左侧：方向键（主/副方向）、视角控制
- 右侧：GUI、背包、键盘、TAB
- 顶部：鼠标开关

![游戏画面1](/assets/img/mc-launcher/pojav-gameplay1.jpg)
![游戏画面2](/assets/img/mc-launcher/pojav-gameplay2.jpg)

### 6. 安装 Forge

如需使用 Forge 模组，可以在手机浏览器中下载 Forge 安装器，然后在 PojavLauncher 中安装对应版本。

![Forge下载](/assets/img/mc-launcher/pojav-forge-download.jpg)

### 7. 光影设置

安装 Optifine 后可以使用光影包，推荐 Open4es 光影，在画面设置中可以调整各项参数。

![光影设置](/assets/img/mc-launcher/pojav-shader.jpg)

## 二、HMCL-PE 启动器

HMCL-PE（Hello Minecraft! Launcher Pocket Edition）是 HMCL 的 Android 移动端版本，功能更加丰富。

### 1. 安装

下载 HMCL-PE 的 APK 安装包后直接安装。

![安装APK](/assets/img/mc-launcher/hmclpe-install.jpg)

### 2. 添加离线模式账户

打开 HMCL-PE，点击"添加离线模式账户"，输入用户名（随意填写）即可创建离线账号。

![添加账户](/assets/img/mc-launcher/hmclpe-account.jpg)

### 3. 安装 OptiFine

HMCL-PE 内置了版本管理功能，可以直接在启动器内安装 OptiFine 等模组加载器，无需额外操作。

![安装OptiFine](/assets/img/mc-launcher/hmclpe-optifine.jpg)

### 4. 启动器主界面

HMCL-PE 的主界面包含：
- 左侧导航栏：新闻、开发控制台、崩溃日志、设置
- 版本选择和启动按钮
- 账户管理

![主界面](/assets/img/mc-launcher/hmclpe-main.jpg)

### 5. 自定义控制

HMCL-PE 支持丰富的控制布局自定义：
- 悬浮窗
- 侧边栏
- 侧滑手势
- 不锁定悬浮窗
- 联机模块菜单
- 高级输入

![控制设置](/assets/img/mc-launcher/hmclpe-controls.jpg)

### 6. 进入游戏

启动后进入 Minecraft Java Edition 主界面，与电脑版完全一致。

![游戏主菜单](/assets/img/mc-launcher/hmclpe-mc-menu.jpg)

### 7. 游戏画面

HMCL-PE 的操控同样支持虚拟按键和鼠标模拟，游戏体验流畅。

![游戏画面](/assets/img/mc-launcher/hmclpe-gameplay.jpg)

### 8. 光影与画面设置

同样支持 OptiFine 光影，在画面设置中可以调整各项参数，获得更好的视觉体验。

![光影设置](/assets/img/mc-launcher/hmclpe-shader.jpg)

## 四、常见问题

**Q: 手机配置要求是什么？**
A: 建议 4GB 以上内存，64位处理器。视频中测试使用的是腾讯黑鲨游戏手机3。

**Q: 可以玩模组吗？**
A: 可以，PojavLauncher 和 HMCL-PE 都支持 Forge 和 Fabric 模组加载。

**Q: 光影会卡吗？**
A: 取决于手机性能和光影包复杂度，Open4es 是比较轻量的选择。
